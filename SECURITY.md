# Security Policy

## Reporting a vulnerability

Do not report security vulnerabilities in a public GitHub issue.

Send the report to: [support.cad@median-dxz.xyz](support.cad@median-dxz.xyz)

Include the affected version, a minimal reproduction or proof of concept, the potential impact, and any suggested mitigation. Please do not publicly disclose the issue until we have had a reasonable opportunity to investigate it.

Security fixes are considered for the latest published release of Cookie AutoDelete Next Edition.
