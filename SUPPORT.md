# Support

Use the repository's issue forms for bug reports, support questions, and feature requests.

Before opening an issue, include:

- Browser name and version
- Cookie AutoDelete Next Edition version
- Operating system
- Steps to reproduce the issue
- Expected and actual behavior
- Relevant sanitized logs or screenshots

Do not include cookies, session identifiers, passwords, access tokens, or other sensitive data.

For security vulnerabilities, do not open a public issue. Follow [SECURITY.md](SECURITY.md).
